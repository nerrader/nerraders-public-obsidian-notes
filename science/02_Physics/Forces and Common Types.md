# What are Forces?

> [!ABSTRACT] Introduction
> 
> Forces are a push or pull resulting from interaction between objects, it is an action that can change an object's shape, velocity, or pressure. It is a [[00_SI Units#Vector Quantities (Magnitude + Direction)|vector quantity]], measured using Newtons (N).

## Types of Forces

Forces are generally categorized into two main types based on interaction.

- **Contact Forces**: These occur when objects physically touch. This includes friction, normal force, tension, air resistance, and applied force.
- **Non-Contact (Field) Forces**: These act over distances without physical contact. This includes [[Gravity|gravity]], [[Electromagnetism|electromagnetic force]], and both the [[Strong Nuclear Force|strong]] and [[Weak Nuclear Force|weak]] nuclear forces.

## List of Common Forces

| Force        | Symbol       | Description                                |
| ------------ | ------------ | ------------------------------------------ |
| Weight       | $F_g$ or $W$ | The gravitational pull on an object's mass |
| Normal Force | $F_n$        | Support force exerted by a surface         |
| Friction     | $f$          | Resistive force opposing motion on land    |
| Drag         | $D$          | Resistive force opposing motion in fluids  |
| Tension      | $T$          | Force transmitted through string or wire   |
