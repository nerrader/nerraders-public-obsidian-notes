Pulleys are a type of [[00_Simple Machines|simple machine]].

One pulley by itself only changes the direction of the effort.
However, multiple pulleys can create [[00_Simple Machines#Mechanical Advantage|mechanical advantage]] by reducing the effort force required to move a load.

![[Pasted image 20260829143456.png]]

The weight of the load is distributed through multiple sections of ropes, so the load force is distributed across multiple rope, meaning you'll need less effort to fully pull up the rope.

An easy way to figure out the mechanical advantage is just to see how many ropes are holding up the load, which in this case is 4.
## Types of Pulleys

![[Pasted image 20260829144124.png]]

- **Fixed**: Only change the direction of the effort.
- **Movable**: Attaches to the load itself, has a mechanical advantage of two.
- **Compound**: Combining both fixed and movable pulleys, which can provide greater mechanical advantage, however it does require more rope to be pulled.
