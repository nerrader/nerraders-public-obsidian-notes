Speed is described as how **fast an object is moving**, and it's SI unit is $m/s$. 

- Speed is calculated using the formula $speed = \frac{distance}{time}$
- Unlike velocity, which is a [[Scalar and Vector Quantities#Vector Quantities (Magnitude + Direction)|vector quantity]]. Speed is a [[Scalar and Vector Quantities#Scalar Quantities (Magnitude)|scalar quantity]], meaning it has no direction, only magnitude.

---

There are also multiple different types of speed, like:

- **Average Speed**: Calculated using $\frac{total distance}{total time}$.
- **Instantaneous Speed**: The average speed in one specific instant. If your speedometer shows $60km/h$ on that time period, your instantaneous speed is $60km/h$.
  
- **Uniform Speed**: The speed remains constant over time. If you sprint the first lap in 20s and the next in 20s, that is uniform speed.
- **Non-Uniform Speed**: The complete opposite of uniform speed. Most real life motion is non-uniform.
