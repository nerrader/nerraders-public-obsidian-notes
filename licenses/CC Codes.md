> [!CAUTION] Don't use CC Licenses for software/source code licensing.
> 
> Do not use CC Licenses for software licensing, CC Licenses are supposed to be use for creative content like books, photos, music, videos, etc. Check out other licenses for software licensing.

The creative commons license has multiple codes/conditions that you can combine together to create your preferred license.

| Abbreviation | Name           | Description                                              |
| ------------ | -------------- | -------------------------------------------------------- |
| BY           | Attribution    | You must give credit to the original owner.              |
| NC           | Non-Commerical | Others cannot use it for commerical purposes.            |
| SA           | Share-Alike    | Changing the work requires them to use the same license. |
| ND           | No Derivatives | Others can use but not change your work.                 |
As said before, you can chain these codes/abbreviations like CC BY-NC-SA 4.0##
